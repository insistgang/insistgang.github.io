# LMCC 成人组第二轮考试逆向分析报告

更新时间：2026-09-19。证据优先级：2026 官方通知与大纲 > 2025 官方真题/解析/代码 > 训练计划推断。

## 1. 第二轮到底考什么

官方确认：第二轮是 3 小时编程机试，重点为大模型应用、训练和微调实践。

2025 成人组真实代码进一步说明，实践并不等于从零训练一个大模型。考生面对的是给定评测脚手架，在限定的 `submission.py` 中完成：

1. Prompt 和生成参数设计；
2. 严格结构化输出；
3. PyTorch 张量计算；
4. Embedding 检索、相似度排序和最小 RAG；
5. 在隐藏测试数据上稳定通过评测。

因此，第二轮的核心不是“背很多 LLM 名词”，而是**读清工程契约、写出短而稳的实现、用自测识别边界、避免对可见数据过拟合**。

## 2. 与第一轮的最大区别

| 第一轮 | 第二轮 |
|---|---|
| 客观题，考概念辨析 | 编程题，考可运行实现 |
| 知道定义即可得分 | 必须遵守函数签名、输入/输出和评测规则 |
| 题目独立 | 可能有共享脚手架、数据文件和隐藏最终集 |
| 常见失分是概念混淆 | 常见失分是 JSON、维度、排序、边界和文件契约 |

## 3. 2025 真题反推的最重要 10 个能力

1. **评测器阅读能力**：先找出可修改文件、函数签名、输入输出和评分条件。
2. **Python 数据处理**：字典、列表、枚举、排序、JSON/JSONL 与路径。
3. **严格 JSON 输出**：字段、类型、数组长度、无额外文字。
4. **Prompt 契约设计**：任务、输入、输出、规则、反例和终止条件清晰分层。
5. **隐藏集泛化意识**：不能把自测题号、答案、格式写死在 Prompt 或代码里。
6. **PyTorch 张量基本功**：shape、点积、范数、`.item()`。
7. **余弦相似度**：公式、`F.cosine_similarity`、排序方向和零向量风险。
8. **Embedding 检索**：查询向量、题库向量、Top-K、稳定排序。
9. **最小 RAG**：把参考题/证据与当前任务清楚区分后再生成。
10. **调试与验收**：用自测、异常输入和输出解析器做回归检查。

## 4. S/A/B/C 优先级

### S 级：现场必须独立写出

- 评测器/README 逆向阅读。
- Python JSONL、列表/字典、排序、函数签名。
- JSON 结构化输出与简单输出校验。
- Prompt 的输入/输出契约和抗干扰示例。
- PyTorch 余弦相似度、Top-K 检索。
- Embedding + RAG 消息组装。
- 面向隐藏测试集的通用解法。

### A 级：高概率出现，需独立完成

- Transformers 的 `AutoTokenizer`、`AutoModel`、`eval()`、`torch.no_grad()` 基本推理流程。
- 平均池化获取 embedding、attention mask。
- 生成参数：`max_new_tokens`、`do_sample`、temperature/top-p 的适用边界。
- 文件/数据/模型加载失败的基本定位。

### B 级：理解并能改模板

- Dataset/DataLoader、基础训练循环。
- LoRA/PEFT 的最小配置与 adapter 保存加载。
- Accuracy/Precision/Recall/F1 与简单评测。
- 简单文本分类与生成任务。

### C 级：暂不投入大量时间

- 完整 RLHF/DPO/GRPO 训练。
- 复杂 Agent、多智能体框架、Function Calling 平台集成。
- FAISS/向量数据库工程部署、复杂量化和多机并行训练。

理由：这些内容在大纲里存在，但 2025 成人组第二轮未直接要求；在只剩 4 周时，应先为已出现且可计分的能力投入时间。

## 5. 2026 的不确定性与应对

2026 官方大纲覆盖范围很广，包含提示学习、检索增强、智能体、指令微调、LoRA、模型评测等；但 2026 成人组第二轮尚未公开题目、代码包、确切库版本和评分细则。

本仓库的对策：

- 用 2025 T1/T2 作为 S 级基本盘。
- 每周加入少量“主题替换”变式：文本抽取、FAQ RAG、结构化信息、轻量微调模板。
- 所有练习使用可替换的接口，避免绑定 2025 的模型名、Conda 环境或数据格式。
- 等官方 2026 代码/考场说明发布后，再用它校正环境与模拟题。

## 6. 当前结论

你的第一优先不是学 LoRA 或 Agent，而是：

```text
读评测器 → 写 submission.py → 严格 JSON → cosine → Top-K → RAG → 隐藏集思维 → 限时调试
```

这条链路覆盖了 2025 真实 100 分的全部能力，并与 2026 官方“应用、训练、微调实践”方向一致。
