# 练习 02：单位与括号

难度：基础+。训练模型忽略单位、括号和过程文字，但不能忽略真正的最终数值。

## 规则

每名学生回答 4 道题：

1. 3 箱，每箱 12 瓶，共 36 瓶。
2. (54 - 14) ÷ 5 = 8。
3. 1.5 升 = 1500 毫升。
4. 23 + 19 = 42。

输出字段不变，但 `judgements` 必须有 4 个布尔值。数据在 `data/test_data.jsonl`；答案在单独的 `answers/`。

自测时将自己的原始模型输出写入 `my_outputs.jsonl`，再运行：

```bash
python ../../tools/t1_scorer.py --outputs my_outputs.jsonl --answers ../../answers/02_单位与括号_expected.jsonl
```
