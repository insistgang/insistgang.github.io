# 练习 01：数字提取入门

难度：基础。目标是熟悉“学生文本 → 布尔数组 → 纯 JSON”的完整闭环。

## 规则

每名学生回答 3 道题：

1. 8 + 7 = 15
2. 30 - 12 = 18
3. 4 × 6 = 24

读取 `data/test_data.jsonl`，为每名学生生成：

```json
{"student_id":"...","judgements":[true,false,true]}
```

要求：只输出 JSON，不要 Markdown、解释或前后缀。完成后将模型原始输出逐行写到你自己的 `my_outputs.jsonl`，每行形如：

```json
{"student_id":"student_101","raw_output":"{\"student_id\":\"student_101\",\"judgements\":[true,true,true]}"}
```

自测命令：

```bash
python ../../tools/t1_scorer.py --outputs my_outputs.jsonl --answers ../../answers/01_数字提取入门_expected.jsonl
```
