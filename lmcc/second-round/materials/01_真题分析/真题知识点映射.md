# 2025 真题知识点映射

| 能力 | 2025 直接证据 | 2026 准备级别 |
|---|---|---|
| Python 函数、列表、字典、排序、JSON/JSONL、路径 | T1/T2 `submission.py` 与 `evaluate.py` | S |
| 阅读评测器与文件契约 | 仅允许改 `submission.py`，最终数据隐藏 | S |
| System Prompt 设计 | T1、T2 均要求实现 | S |
| 严格 JSON 结构化输出 | 两题均按 JSON 结果计分 | S |
| Prompt 的泛化与抗过拟合 | 自测与最终数据不同 | S |
| PyTorch 张量与余弦相似度 | T2 单独 20 分 | S |
| Embedding、Top-K 排序、RAG 消息组装 | T2 直接考核 | S |
| Transformers 推理与 tokenizer/chat template | 2025 评测器负责大部分流程，但考生需理解接口 | A |
| 生成参数、确定性解码、输出长度 | 两题均要求实现 generation parameters | A |
| LoRA/PEFT、训练循环、量化、Agent | 2026 大纲覆盖，但 2025 真题未直接考 | B |
| FAISS、向量数据库、Function Calling、多智能体框架 | 2025 真题未直接需要 | C |

结论：先把 S 级练到闭卷可写，再做 A 级；B/C 只在真题基础稳定后用短模板覆盖。
