# 2025 T1：数学作业批改助手

## 题目任务

通过 Prompt 与生成参数，让模型完成“非结构化作业文本 → 5 个真假判断 → 严格 JSON”的转换。

## 真正考察的能力

1. 读懂题目、评测器与允许修改边界。
2. 给模型提供任务目标、标准答案、输入格式、边界样例与输出约束。
3. 从带评论、表情、计算过程的文本中抽取核心数字。
4. 坚持纯 JSON 输出：不要 Markdown 代码块、不要额外解释。
5. 用可见自测验证格式，但不针对自测样本硬编码。

## 最容易失分的位置

- 忘记原样回传 `student_id`。
- `judgements` 不是 5 个 JSON 布尔值。
- 输出前后夹带“下面是结果：”或 Markdown 代码块。
- 只匹配第一个数字，而没有依题目判断最终答案。
- Prompt 只适配自测中的文字样式，隐藏数据一换格式就失败。

## 2026 价值判断

**S 级。** 即便题目主题从数学改为分类、信息抽取或文本审核，输入解析、输出契约、稳健 Prompt、隐藏集泛化与评测器阅读仍然完全可迁移。

## 训练变式

1. 订单信息抽取：输出订单号、总价、风险标签。
2. FAQ 事实核验：输出 claim 与 evidence-supported 的布尔数组。
3. 表格文本清洗：输出固定字段 JSON，字段缺失时给空值。
