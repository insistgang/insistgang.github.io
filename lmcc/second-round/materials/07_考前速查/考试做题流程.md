# 考试做题流程

## 0–15 分钟：逆向评分器

1. 读 README。
2. 找出允许修改的文件和函数签名。
3. 看 evaluator 如何读数据、调用函数、解析输出、计分。
4. 写下输入字段、输出字段、数组长度、每部分分值和时间限制。

## 15–35 分钟：先跑 baseline

1. 不改 evaluator。
2. 用 starter 跑一次 demo，记录报错、模型原始输出和当前分数。
3. 先修 import、路径、函数签名和 JSON 契约。

## T1：实现与自测

1. Prompt 中列规则/标准答案。
2. 明确“最终核心答案，忽略噪声”。
3. 约束纯 JSON、原样 ID、布尔数组。
4. 用含多数字、评论、表情的样例自测。

## T2：实现与自测

1. 先完成 cosine 并验证相似度 Top-1。
2. 再完成 Top-K 排序与切片。
3. 再组装当前题与参考题。
4. 最后调 system prompt 和 JSON answer。

## 最后 20 分钟：隐藏场景思维

1. 删掉公开题号、公开答案、固定文本格式依赖。
2. 检查空题库、top_k、零向量与数组长度。
3. 用 demo 看模型完整输出，确认没有 Markdown 或多余文本。
4. 检查只提交允许修改的文件。

## 最后提交检查

- 输入/输出路径正确。
- JSON / JSONL 无语法错误。
- T1 bool、T2 answer 类型正确。
- 公开自测跑完。
- 不依赖公开数据硬编码。
- 最终保存和提交状态确认。
