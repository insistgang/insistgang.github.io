# T1 考前速查

## 10 秒识别题型

```text
给定自然语言作业文本
→ 提取每题最终核心答案
→ 和标准答案比较
→ 输出严格 JSON 布尔数组
```

## Prompt 模板

```text
你是[任务]助手。输入含 student_id 与 N 道作答。

标准答案/规则：
1. ...
2. ...

执行：
1. 原样保留 student_id。
2. 对每题提取最终核心答案，忽略评论、表情、过程和无关数字。
3. 按顺序生成 N 个 true/false。

只输出一个合法 JSON 对象；不要解释、前后缀或 Markdown：
{"student_id":"...","judgements":[true,false,...]}
```

## JSON 模板

```json
{"student_id":"student_001","judgements":[true,false,true,true,false]}
```

## 生成参数

```python
{
    "max_new_tokens": 1024,
    "do_sample": False,
    "enable_thinking": True,
}
```

## 常见错误

- 输出 `True/False`、`1/0` 或字符串，而不是 JSON `true/false`。
- 漏掉 ID、改写 ID、判断数组长度错。
- `结果如下：`、Markdown 代码块污染输出。
- 只取第一个数字，不看题目对应关系。
- 用自测里出现的学生文本写死 Prompt。
- 未运行 demo 查看模型原始输出。

## 现场步骤

1. 读允许修改的函数和评测器的 JSON 解析逻辑。
2. 写短 Prompt：任务 + 标准答案 + 提取规则 + 输出契约。
3. `do_sample=False`，给足 `max_new_tokens`。
4. 先验证 JSON，再验证每题判断。
5. 用含评论、表情、多个数字的样例做最后一次回归。
