# T2 考前速查

## 10 秒识别题型

```text
给 query 和 problem_bank
→ embedding
→ cosine
→ Top-K
→ 参考题 + 当前题组装
→ 只输出 {"reasoning":"...","answer":"数字"}
```

## cosine 模板

```python
query = query_embedding.flatten().float()
doc = doc_embedding.flatten().float()
denom = query.norm() * doc.norm()
if denom.item() == 0:
    return 0.0
return ((query @ doc) / denom).item()
```

## Top-K 模板

```python
scored = []
for index, item in enumerate(problem_bank):
    emb = get_embedding_func(item["problem"], embedding_model, tokenizer)
    scored.append((compute_similarity(query_emb, emb), index))
scored.sort(key=lambda pair: (-pair[0], pair[1]))
return [problem_bank[index] for _, index in scored[:top_k]]
```

## RAG 消息模板

```text
【当前问题】
...

【检索到的参考题】
参考题 1（ID=...）
题目：...
解析：...
答案：...

参考题只用于学习方法；独立计算当前问题。
```

## 输出模板

```json
{"reasoning":"简洁过程","answer":"63"}
```

## 调试顺序

1. 先看 `compute_similarity` 是否为 float、是否除 norm。
2. 再看排序是不是降序、Top-1 是否正确。
3. 再看用户消息是否包含当前题与参考题。
4. 最后看 JSON、`answer` 是否只含数字。

## 最易丢分

- 点积当 cosine。
- 排序反向。
- 复制参考答案而不重新计算。
- `answer` 带单位。
- 输出代码块/解释。
- 针对自测题号硬编码。
