# 看到题型 → 应想到的代码

| 题目线索 | 第一反应 | 最小代码/动作 |
|---|---|---|
| 作业、评论、表情、判断对错 | T1 文本抽取 | system prompt 写标准答案、最终答案提取、布尔 JSON |
| 固定字段、严格格式、JSON | 输出契约 | 只输出对象；检查字段、类型、长度 |
| 向量、相似、embedding | cosine | dot / (norm × norm)，再 .item() |
| 题库、最相关、前 K 条 | Top-K | 遍历得分、降序排序、切片 |
| 参考题、知识库、上下文 | 最小 RAG | 当前题和参考题分块组装 |
| 当前题数字不同但关系相同 | 不复制答案 | 从参考解析提取方法，重新计算 |
| self test 与 final 不同 | 隐藏集意识 | 不按 ID/示例答案写规则 |
| TODO、submission.py、evaluate.py | 评测器驱动 | 先读评分函数，再写最短实现 |
