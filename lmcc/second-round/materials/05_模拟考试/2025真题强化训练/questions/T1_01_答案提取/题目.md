# T1-01：基础答案提取

风格：2025 T1 的缩小版。实现 `starter.py` 中的两个函数。

每名学生回答 3 道题：

1. 14 + 16 = 30
2. 50 - 23 = 27
3. 5 × 8 = 40

只可输出：

```json
{"student_id":"...","judgements":[true,false,true]}
```

公开输入在 `data/t1_public.jsonl`；隐藏输入和参考输出在 `../../answers/T1_01_答案提取/`。不要看隐藏数据后再改 Prompt。

运行：

```bash
python evaluate.py --outputs ../../answers/T1_01_答案提取/demo_outputs.jsonl --scope public
```
