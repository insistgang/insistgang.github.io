Prompt 的约束顺序

先角色与任务，再给字段和类型，接着给原文，最后明确“只输出 JSON，不要 Markdown”。

prompt = f"""你是批改助手。
从题目文本抽取答案并判断对错。
只输出一个 JSON 对象，不要解释、不要 Markdown。
字段：answer(str), is_correct(bool), reason(str)
题目：{question}
学生答案：{student_answer}"""

评测器的硬边界

一行一条 JSON、字段完整、类型正确、不能多字、输入多少条就输出多少条。先验证再提交。

record = json.loads(model_text.strip())
assert isinstance(record["answer"], str)
assert isinstance(record["is_correct"], bool)
assert isinstance(record["reason"], str)
print(json.dumps(record, ensure_ascii=False))

cosine similarity + Top-K

先防止零向量，再按分数降序取 K 个索引。并列和输入维度都要按题面/评测器处理。

q = F.normalize(query.float(), dim=-1)
d = F.normalize(docs.float(), dim=-1)
scores = d @ q
top_scores, top_ids = torch.topk(scores, k=top_k)
retrieved = [documents[i] for i in top_ids.tolist()]
